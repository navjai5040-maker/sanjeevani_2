# Data model

The durable database model centers around these entities:

- users
- roles
- patients
- providers
- facilities
- departments
- services
- specialists
- diagnostics
- medicines
- facility_status
- appointments
- queues
- care_requests
- triage_results
- care_matches
- referrals
- referral_events
- teleconsultations
- followups
- notifications
- audit_logs

The platform favors normalized storage and explicit state transitions to maintain accountability across facilities and workflows.
